# Dyotona documentation

Dyotona is an embeddable AI shopping agent for small and medium stores. Merchants paste a script tag. Shoppers chat in English or Bengali against a **synced catalog**. Owners get inbox, analytics, and (for WooCommerce) native add-to-cart and order lookup.

Production hosts: `dyotona.com` (dashboard) · `api.dyotona.com` (API + widget). See [railway.md](./railway.md).
